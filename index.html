01Acceptance of Terms
By accessing ThreatScope you accept these terms. If you disagree, do not use this service.
// Plain English
Use this tool responsibly. Only scan websites you own or have explicit permission to test. GitHub Discovery shows paginated public search results and offers exact lookups; it does not crawl the full GitHub catalog.
02Description of Service
ThreatScope is a defensive intelligence dashboard. It is a static website on GitHub Pages with no backend servers. API requests go directly from your browser to third-party services. The vulnerability catalog uses CISA data delivered by a daily public mirror. GitHub Discovery queries public repositories through GitHub’s search API and displays the repository’s last-push date; the exact default-branch commit date is requested only when you choose it for a card. Search does not enumerate every public repository or crawl repository contents.
03Acceptable Use Policy
Authorised Use
Only scan URLs and domains you own, control, or have explicit written permission from the owner to test.
Security Research
Legitimate security research, academic study, and professional penetration testing where proper authorisation has been obtained.
Educational Use
Reference libraries and public threat feeds are provided for defensive and educational purposes. ThreatScope does not report attacker locations or live attack telemetry.

05API Keys & Third-Party Data
ThreatScope does not store API keys. Keys are held in browser memory for your page session and are sent directly to the provider when you request a lookup. URLs you scan are sent directly from your browser to third-party services. The CISA KEV catalog is fetched from the AboutCode public mirror, which refreshes daily from CISA.
06Disclaimers & Liability
Accuracy
Results come from third-party engines. Do not use as the sole basis for security decisions. False positives and negatives are possible.
Data freshness
The CISA KEV catalog mirror is refreshed daily. Public GitHub repository metadata is fetched on demand and is subject to GitHub API availability and rate limits. Neither source should be interpreted as a complete or real-time view of global risk.
Limitation of Liability
To the maximum extent permitted by law, ThreatScope contributors shall not be liable for any damages arising from use of this service.
07Privacy Policy
// The Short Version
ThreatScope does not run analytics or persist feedback in this app. Theme selection and Site Guide messages stay in page memory; the guide is not generative AI and does not send prompts to an AI service. If you choose to submit a prepared issue, GitHub receives it and published issues are public. Third-party services may receive standard network metadata when your browser requests their content or scans.
Data Collection
ThreatScope does not use cookies, local storage, tracking pixels, or fingerprinting. Feedback text, theme selection, and Site Guide messages are held only in the current page and are not sent to an AI provider. Feedback is sent to GitHub only if you open the prepared draft; nothing is submitted automatically, and issues are public if you submit them. Third-party services receive requests directly from your browser and may process standard connection metadata under their own privacy policies.
Hosting & Threat Feed
GitHub Pages hosts this website. The KEV feed is delivered by the AboutCode mirror hosted on GitHub. Repository search terms are sent to GitHub's public API, and exact repository metadata or commit lookups are requested when you choose them. GitHub and other service providers may collect standard server logs. Review each provider's privacy policy.
